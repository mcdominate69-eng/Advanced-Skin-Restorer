# Advanced Skin Restorer

A lightweight Fabric modpack focused on **reliable skin restoration** (especially useful for cracked/offline-mode players) + strong performance optimizations.

**Modrinth**: [https://modrinth.com/modpack/advanced-skin-restorer](https://modrinth.com/modpack/advanced-skin-restorer)

---

### Features
- Persistent custom skins even on offline-mode servers
- Fixes for skin override flickering / invalid state issues
- Instant skin updates via commands
- Heavy focus on performance (Sodium, Lithium, ImmediatelyFast, Entity Culling, FerriteCore, etc.)

---

### Requirements
- Minecraft **1.21.x** (and newer versions listed on Modrinth)
- **Fabric** loader

---

### Installation
1. Install the [Modrinth App](https://modrinth.com/app) (recommended)
2. Search for **Advanced Skin Restorer** and install
3. Or download the `.mrpack` from the Modrinth page and import it into Prism Launcher / MultiMC / etc.
